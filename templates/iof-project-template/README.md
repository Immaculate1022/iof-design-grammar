# IOF Project Template

This template provides a basic starter structure for projects aligned with the Infinite Optical Fabric (IOF) Design Grammar. It embodies the core principles of semantic compression, four-level consistency, and governance primitives.

## Getting Started

1.  **Clone this template.**
2.  **Review `config.json`:** Adjust project metadata and initial parameters.
3.  **Implement your core logic:** Start building your simulation, visualization, or system using IOF protocol primitives.
4.  **Integrate Trust Layer:** Ensure clear attribution, licensing, and privacy statements.

## Structure

-   `README.md`: Project overview and setup instructions.
-   `config.json`: Project metadata, initial parameters, and IOF-specific configurations.
-   `src/`: Source code for your application, organized by IOF primitives (e.g., `src/resonance/`, `src/coherence/`).
-   `docs/`: Documentation, including governance statements and architectural diagrams.
-   `LICENSE`: IOF Attribution License or compatible license.

## IOF Alignment Checklist

Before deployment, ensure your project adheres to the IOF Design Grammar:

-   [ ] **Protocol Primitives:** Are core concepts (resonance, coherence, topology, etc.) consistently applied as operational constraints?
-   [ ] **Four-Level Consistency:** Is there alignment across aesthetic, semantic, architectural, and governance layers?
-   [ ] **Governance Primitives:** Does the system embody inspectability, interoperability, and distributed authority?
-   [ ] **Trust Layer:** Is provenance, permissions, privacy, and intent clearly communicated?
-   [ ] **Development Philosophy:** Does it prioritize portability, inspectability, and frictionless sharing?

For detailed guidance, refer to the `iof-design-grammar` skill documentation.
